# Design: add-checkpoints

- `is_checkpoint(seed, bridge, roof_layer)`: `0 ≤ roof_layer − cell_a.y < checkpoints.layers` and
  `u01(hash(seed, SALT_CHECKPOINT, cell_a, axis)) < checkpoints.share`. Checkpoints come before gang
  claims on the same bridge.
- Offers reuse the encounter flow (pay, talk, run); kind "contraband" turns run into confiscation
  of the contraband and data jobs. The authority is the first city power of type "authority".
